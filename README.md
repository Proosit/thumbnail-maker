# サムネイルメーカー

YouTube用サムネイル（1280×720）を、ブラウザだけで作れるツールです。インストール不要で、画像の処理はすべて端末の中で行われます（外部に送信されません）。

## 使い方

`index.html` をブラウザで開くだけで動きます。GitHub Pages で公開すると、iPhoneのSafariから開いて「ホーム画面に追加」でアプリのように使えます。

## 主な機能

- **レイヤー**：背景・人物・本の表紙・素材など、画像を何枚でも重ねられる。文字の前後も自由
- **画像ごとの効果**：明るさ、コントラスト、白黒、色かぶせ、暗さ、ぼかし、輪郭ぼかし、回転、影・後光、重ね方（スクリーン等）
- **文字**：自由な行レイアウト／白箱テンプレート、日本語フォント28種＋手持ちフォント、縁取り（二重）、影、グラデーション、かすれ・金・銀の質感、`*強調*` 記法
- **仕上げ**：周辺減光、粒子感、背景色
- **保存**：作業の自動保存（端末内）、マイプリセット、バックアップファイル（.json）の書き出し・読み込み
- **書き出し**：PNG（1280×720）

## 補足

- 作業データは開いている場所（URL）ごとに端末のブラウザ内へ保存されます。別の場所へ移るときは「保存」タブのバックアップで引き継げます。
- フォントは Google Fonts から読み込みます（初回のみ通信が発生します）。
