# サムネイルメーカー

YouTube用サムネイル（1280×720）を、ブラウザだけで作れるツールです。インストール不要で、画像の処理はすべて端末の中で行われます（外部に送信されません）。

## 使い方

`index.html` をブラウザで開くだけで動きます。GitHub Pages で公開すると、iPhoneのSafariから開いて「ホーム画面に追加」でアプリのように使えます。

## 主な機能

- **レイヤー**：画像も文字も何枚でも重ねられる。グループ化（入れ子可）でまとめて移動・拡大・回転
- **自由配置**：ドラッグ・2本指で拡大回転。画面の中央や端、他のレイヤーの端に吸い付くガイド、揃えボタン
- **効果（画像・文字・塗りつぶし・グループ共通）**：明るさ、コントラスト、白黒、色かぶせ、暗さ、ぼかし、輪郭ぼかし、不透明度、重ね方（スクリーン等）、周辺を暗く、粒子感、影・後光
- **「全体」グループ**：一番上の「全体」に効果をかけると画面全体にかかる。背景色は「塗りつぶし」レイヤー
- **文字**：行ごとの大きさ・ずらし、日本語フォント28種＋手持ちフォント、縁取り（二重）、影、グラデーション、`*強調*` 記法
- **文字の質感（9種・それぞれ専用の設定）**：かすれ（点/筋/ムラ）、筆のかすれ、錆・ダメージ、金属（金・銀・銅・好きな2色）、光沢、立体（浮き出し/彫り込み）、網点、ストライプ、画像で塗る
- **箱**：塗りつぶし／枠線／マーカー／下線。強調部分だけ・行ごと・レイヤー全体を囲める（白箱テンプレート付き）
- **テンプレート**：文字レイヤーを自分のテンプレートとして保存
- **保存**：作業の自動保存（端末内）、マイプリセット、バックアップファイル（.json）の書き出し・読み込み
- **書き出し**：PNG（1280×720）

## 補足

- 作業データは開いている場所（URL）ごとに端末のブラウザ内へ保存されます。別の場所へ移るときは「保存」タブのバックアップで引き継げます。
- フォントは Google Fonts から読み込みます（初回のみ通信が発生します）。
